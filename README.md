# La casa de la Sabiduría

«La Sabiduría se ha construido su casa, ha labrado sus siete columnas» (Prov 9, 1).

Recorrido para la oración por el libro de los Proverbios en un templo circular 3D, de noche. Cada columna se enciende al recorrerla; al final se ilumina la mesa del centro.

| Columna | Tema | Proverbio principal |
|---|---|---|
| I | El temor del Señor | Prov 9, 10 |
| II | La lengua | Prov 15, 1 |
| III | El trabajo | Prov 6, 6-8 |
| IV | La familia | Prov 1, 8-9 |
| V | La amistad | Prov 17, 17 |
| VI | La humildad | Prov 16, 18 |
| VII | La justicia y el pobre | Prov 19, 17 |
| ✦ | La mesa servida | Prov 9, 1-6 · 1 Cor 1, 23-24 |

Cada columna: texto, proverbio, dos más «para rumiar», eco del Evangelio, pregunta para la oración, lectura y botón de WhatsApp. Al final, «Un proverbio para hoy» (cambia cada día).

## Publicar en GitHub Pages
1. Crea el repositorio `casa-sabiduria` y sube todo el contenido de esta carpeta a la raíz.
2. *Settings → Pages → Deploy from a branch → main / (root)*.

## Técnica
HTML + CSS + JS sin compilación; Three.js r160 incluido en `js/`. Sin WebGL se muestra un templo dibujado en SVG. Respeta `prefers-reduced-motion`. Variante pastoral «noche, oro y silencio».
